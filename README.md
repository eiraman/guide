# The Eiraman Guide

Eiraman is a management method for governed vibe coding: AI-built software directed by a Human Manager. Business people govern multi-agent AI development as managers, and every release can be reconstructed from evidence and costs.

The Eiraman Guide by Paolo Ungari and contributors.

This repository holds the **Eiraman Guide**, the stable core of the method, with the community-maintained sections on Digital Seniority, test practices and adoption levels. Templates, indicative values, Role Profiles and tools live in separate repositories of the project.

**Status:** version 1.0.0-rc.2, a release candidate, with RFC 0001 (accepted). The Author ratified its editorial choices on 25 November 2026. Not yet in force.
